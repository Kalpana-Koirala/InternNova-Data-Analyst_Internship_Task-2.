# InternNova-Data-Analyst_Internship_Task-2.	
## 1. NumPy Introduction & Arrays
- Built and inspected NumPy arrays — created 1D and 2D arrays and extracted their shape, size, and data type.

## 2. NumPy Indexing, Slicing & Reshaping
- Accessed specific elements and sub-arrays via indexing/slicing, then reshaped arrays into new dimensions while preserving data integrity.

## 3. NumPy Mathematical & Statistical Operations
- Performed element-wise arithmetic (add, subtract, multiply, divide) & computed key statistics — mean, median, min, max, standard deviation & sum.

## 4. Pandas Series & DataFrame
- Created a Pandas Series and a structured DataFrame of student records, then inspected and extended it with a new column.

## 5. Reading & Inspecting Data
- Loaded a real-world CSV (9,994-row Superstore dataset) and profiled it using head(), tail(), columns, shape, dtypes, info() & describe().

## 6. Selecting, Filtering & Sorting Data
- Queried the dataset with column/row selection, applied single and multi-condition filters, and sorted records in ascending/descending order.

## 7. Handling Missing Values
- Detected and quantified missing data with isnull(), then cleaned it using both row removal (dropna()) & fillna() with using statistical imputation (mean/median/mode).

## 8. Merge, Concatenate, GroupBy & Pivot Table
- Combined multiple datasets via merge/concat, ran GroupBy aggregations (sum, mean, count, min, max), and built pivot tables to summarize data across dimensions.

## 9. Exporting Data
- Exported the final processed DataFrame to CSV.

## 10. Mini Data Analysis Project
- Delivered an end-to-end EDA pipeline on a Student Performance dataset — cleaned missing scores, filtered top performers, ran GroupBy/pivot analysis, and surfaced a key insight (0.97 correlation between attendance and performance) before exporting the final cleaned dataset.
